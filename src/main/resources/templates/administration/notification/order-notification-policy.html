행동 주체·작업·수신 대상별로 종 알림, 카카오톡, 강제 중요알림을 각각 제어합니다.

카카오톡 테스트
바로가기 링크 제공 기준

삭제된 오더는 누구에게도 링크를 제공하지 않습니다. 취소·승인 전 상태는 팀 화면에서 조회할 수 없으므로 팀 수신자에게는 링크가 없지만, 모든 상태를 조회할 수 있는 관리자에게는 링크가 유지됩니다.

담당자 변경으로 실제 조회 권한을 잃은 기존 배송 담당자에게는 변경 사실만 전달하며, 현재 권한으로 조회 가능한 수신자에게만 링크가 표시됩니다.

체크됨: 해당 수단으로 전송합니다. 체크 해제 후 저장: 해당 수단으로 전송하지 않습니다.

중요알림은 수신자 화면 전체를 잠그는 강제 확인 팝업으로 표시됩니다. 팝업의 확인 상태와 종 알림의 읽음 상태는 서로 독립적이므로, 팝업에서 확인한 뒤에도 종의 ‘중요알림’ 탭에 미확인 알림이 남습니다. 중요알림을 켠 행은 ‘종 알림’ 스위치가 꺼져 있어도 중요알림 탭에는 기록됩니다.

설정 변경은 저장 이후 새로 생성되는 알림부터 적용됩니다. 이미 발송된 중요알림은 정책을 다시 꺼도 수신자가 강제 팝업에서 확인하기 전까지 유지됩니다.

확인/재확인 행은 사용자별 체크 이력만 저장하고 다른 사람에게 알림을 보내지 않는 감사 전용 항목입니다. 전체 알림 또는 카카오톡 설정이 비활성화되어 있으면 이 페이지에서 체크되어 있어도 해당 수단은 발송되지 않습니다.

중요알림 사용 주의

중요알림은 사용자가 반드시 ‘확인’을 눌러야 화면을 다시 사용할 수 있습니다. 완료·변경 이벤트가 대량으로 발생하는 항목을 무분별하게 켜면 업무 화면이 자주 잠길 수 있으므로 실제로 즉시 확인이 필요한 조합만 활성화해 주세요.
