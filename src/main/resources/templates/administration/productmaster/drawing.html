DRAWING GUIDE

도면 편집 안내

도형·텍스트
왼쪽 도형을 끌어다 놓으세요. 도형을 더블 클릭하면 글씨를 입력할 수 있습니다. 오른쪽 서식 패널에서 선 색·두께·점선·채우기·글꼴을 조절합니다.
정렬·동일 크기
도형 이동·크기 변경 시 정렬, 간격, 동일 폭·높이 안내선이 표시됩니다. 보기 메뉴의 안내선과 격자를 켜고, 정렬 메뉴에서 맞춤·간격 조정·그룹·앞뒤 배치를 사용하세요.
여러 도면
하단의 ＋로 페이지를 추가합니다. 각 탭의 메뉴에서 이름 변경·복제·삭제를 할 수 있습니다. 모든 페이지가 하나의 제품 도면으로 함께 등록됩니다.
복사·실행 취소
Ctrl+C / Ctrl+V로 도형을 복사하고, Ctrl+Z / Ctrl+Y로 실행 취소·다시 실행합니다. Mac에서는 Ctrl 대신 ⌘를 사용합니다.
등록·내려받기
상단 ‘도면 등록’ 또는 Ctrl+S로 제품에 저장합니다. PNG·SVG는 선택 페이지, .drawio는 전체 페이지와 도형 편집 정보를 내려받습니다. 편집기 파일 메뉴에서도 내보내기를 사용할 수 있습니다.
이미지 초안
AI는 기본 구조를 도형으로 해석합니다. 실제 생산 치수나 경첩·점선 등 상세 표현은 결과를 확인한 후 직접 보완해 주세요. 생성과 타제품 불러오기는 기본적으로 기존 페이지 뒤에 추가됩니다.
도면은 화면을 닫기 전에 직접 등록해 주세요.
