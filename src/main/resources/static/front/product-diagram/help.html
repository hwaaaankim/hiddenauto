웹다이어그램으로 개수 응답받기 · 실제 화면 사용 설명서

이 기능은 비규격 숫자입력 질문의 답변을 고객이 배치한 도형 개수로 받습니다. 도면·도형을 설정한 다음 기존 질문 분기와 가격계산에 그대로 연결합니다.

1. 어디서 시작하나요?

관리자 계정으로 제품관리 화면에 들어갑니다. 제품관리 상단 메뉴의 실제 이름과 주소는 다음과 같습니다. 주소는 접속 중인 DEV 또는 본 서비스 도메인 뒤에 붙이는 경로입니다.

하려는 일 화면과 버튼 경로
숫자입력 그룹 생성·설정 그룹·옵션 → + 그룹 또는 기존 그룹 선택 /admin/product-master/groups
그룹을 넣어 비규격 제품 생성 제품 조합 생성 /admin/product-master/products/new
기존 비규격 제품 찾기 비규격 제품 관리 /admin/product-master/non-standard
해당 제품 구성 열기 제품 행의 구성 수정 /admin/product-master/products/제품ID
질문·도형·분기 설정 구성 화면의 비규격 프로세스 /admin/product-master/products/제품ID/process
가격 연결 해당 제품의 가격계산 화면 /admin/product-master/products/제품ID/pricing
전체 고객 흐름 시험 비규격 테스트 / 저장된 제품 고객 테스트 /admin/product-master/products/제품ID/test
고객이 구성하기 고객 메뉴 발주하기 /customer/store-preview
확정한 실제품의 도면 보기 실 제품·재고 → 확정 배치 도면 /team/product-diagram/actuals/실제품ID

제품ID와 실제품ID는 서로 다릅니다. 예를 들어 제품관리 대상 제품의 ID가 123이면 프로세스 주소는 /admin/product-master/products/123/process입니다. 이 123은 주소 형식의 예시이며 특정 제품을 지정한 것이 아닙니다.

전체 순서는 그룹 설정 → 제품 구성 → 숫자 항목 등록 → 도면 설정 → 기존 분기 연결 → 프로세스 저장 → 가격 등록·검증 → 고객 시험입니다.

화면 상단의 도면 응답 사용법 ↗, 단계 안의 **이 단계 사용법 ↗**를 누르면 현재 상황의 설명으로 이동합니다.

2. 공통 그룹에서 무엇을 설정하나요?

  1. 그룹·옵션에 들어갑니다.
  2. 새 그룹이면 + 그룹, 기존 그룹이면 왼쪽 목록의 해당 그룹을 누릅니다.
  3. 그룹 이름을 문의 형태로 정합니다.
  4. 입력 방식은 숫자 입력, 비규격용 그룹과 고객 질문에 포함은 사용으로 설정합니다.
  5. 가격계산에 영향을 주는 그룹을 체크합니다.
  6. 그룹 저장을 누릅니다. 표시된 웹다이어그램으로 응답받기는 제품 설정을 시작할 때의 기본 체크값이며 선택사항입니다. 체크하지 않아도 제품별 프로세스에서 도면 응답을 설정할 수 있습니다.

이 단계의 결과: 공통 그룹의 입력 방식과 사용 기본값을 저장합니다. 여닫이·서랍의 개수 항목, W/H 연결, 좌경첩 도형은 각 제품의 프로세스에서 정합니다. 같은 그룹을 여러 제품에 연결해도 도형 구성은 제품별로 다르게 정할 수 있습니다.

이미 사용 중이라 공통 그룹 편집이 잠긴 경우에는 화면 아래의 독립 설정에서 체크 후 응답 방식 저장을 누릅니다. 제품별 도형은 역시 해당 제품의 프로세스에서 설정합니다.

이미 사이즈 질문과 대상 비규격 제품이 있다면 기존 구성을 사용하시면 됩니다. 새 제품이라면 제품 조합 생성에서 필요한 분류·시리즈·사이즈·문의 형태 등의 그룹을 연결하여 생성합니다.

3. 제품 프로세스에서 개수 항목을 만듭니다

  1. 비규격 제품 관리 → 대상 제품의 구성 수정 → 비규격 프로세스를 엽니다.
  2. 질문·답변 완성 단계에서 사이즈 질문이 문의 형태보다 앞에 있는지 확인합니다.
  3. 사이즈의 답변 등록·수정 → 가능한 답변 등록에서 W·H·D 등의 숫자 필드가 준비되어 있어야 합니다. W/H는 실제 주문 가능한 양의 정수 mm 범위로 설정합니다.
  4. 문의 형태의 답변 등록·수정 → 가능한 답변 등록으로 들어갑니다.
  5. + 입력 필드를 눌러 아래 항목을 만듭니다. 고객·생산·관리용 이름도 기존처럼 작성합니다.
숫자 항목 이름 예시 이 숫자가 의미하는 것
600 이하 서랍 그 항목에 연결된 서랍 도형의 배치 수
600 초과 서랍 그 항목에 연결된 큰 서랍 도형의 배치 수
여닫이 좌경첩·우경첩 도형의 합계 배치 수
오픈선반 오픈선반 도형의 배치 수
  1. 기존 입력 제한 설정에서 필요한 최소·최대 개수와 합계 제한을 정합니다. 도면에서 나오는 개수는 음수와 소수를 사용할 수 없고 간격은 1개입니다. 숫자 기본값으로 배치를 대신 확정하지 않습니다.
  2. 다음 단계의 웹다이어그램 설정 → 웹다이어그램 설정 버튼을 누릅니다.

숫자 항목을 이미 만든 질문에는 메인 질문 카드에 도면 응답 설정 또는 도면 응답 수정 버튼도 표시됩니다. 이 버튼을 누르면 해당 설정 단계로 바로 이동합니다. 구성이 잠긴 조회 화면에서는 등록된 도면 설정에 도면 응답 조회가 표시되고 수정·저장은 할 수 없습니다.

이 단계의 결과: 아직 고객에게는 반영되지 않은 질문 편집 내용입니다. 항목별로 어떤 도형을 배치하면 어느 숫자에 집계할지 다음 단계에서 연결합니다.

4. 도면 설정 1단계: 응답 방식

웹다이어그램으로 응답받기를 체크하고 다음을 누릅니다.

  • 체크: 고객은 답변하기로 배치 화면을 열고, 배치 수가 숫자 답변이 됩니다.
  • 체크 해제 후 다음: 이 제품의 해당 질문을 일반 숫자입력으로 변경합니다. 이 변경도 마지막 프로세스 저장까지 진행해야 반영됩니다.
  • 도형 한 개는 무조건 개수 한 개입니다. 도형 안에 서랍 칸이나 삼각형을 여러 개 그려도 개수는 늘어나지 않습니다.

공통 그룹의 체크만으로 모든 제품에 도형이 자동 생성되지는 않습니다. 이 창에서 제품별 설정을 완성해야 합니다.

5. 도면 설정 2단계: 기본 도면 크기

  1. 도면 가로에 사이즈 → W를 선택합니다.
  2. 도면 높이에 사이즈 → H를 선택합니다.
  3. 목록 대신 위의 숫자 필드 이름을 연결 칸으로 드래그해도 됩니다.
  4. 다음을 누릅니다.

고객이 W=1500, H=800으로 답하면 고객 화면에 1500×800mm 바탕 사각형이 생깁니다. D는 연결하지 않았다면 이 정면도의 크기에 쓰이지 않습니다.

가로와 높이는 서로 다른 앞 질문에서도 가져올 수 있습니다. 선택한 숫자는 mm로 사용합니다. 예를 들어 150cm를 의미하는 150을 연결하면 자동으로 1500mm로 바꾸지 않습니다.

앞 분기 때문에 연결한 W/H를 받지 않는 경로가 있다면 그 경로를 수정하거나 도면 질문도 생략하도록 연결해야 합니다. 필요한 앞 질문을 건너뛴 상태에서 임의의 예시 크기로 실제 답변을 받지 않습니다.

6. 도면 설정 3단계: 항목별 도형 등록

여닫이 카드의 ＋ 도형등록을 누릅니다. 그러면 다음의 별도 도형 등록 창이 열립니다.

6-1. 이름·연결 항목

  • 도형 이름: 좌경첩
  • 개수를 반영할 항목: 여닫이
  • 다음을 누릅니다.

나중에 고객이 좌경첩 2개와 우경첩 1개를 배치하면 여닫이 답변은 3입니다. 종류별 이름은 도면에 보존되므로 좌·우 위치는 구별하여 확인할 수 있습니다.

6-2. 표시 조건

항상 쓸 수 있는 도형이면 조건을 추가하지 않고 다음을 누릅니다.

특정 앞 답변에서만 이 도형을 허용하려면 ＋ 앞 답변 조건 → 앞 질문 → 비교 → 보기 또는 숫자 기준을 선택합니다. 여러 조건을 넣으면 모두 만족해야 합니다.

여기서는 이 도형 종류 하나의 추가 조건을 정합니다. 5개의 숫자 항목을 앞 분기로 3개/2개만 표시하는 기능은 기존 프로세스의 연관관계에서 설정합니다. 두 조건이 함께 적용되므로 숨겨진 항목의 도형이 이 조건으로 다시 나타나지는 않습니다.

6-3. 외곽 형태

여닫이 예시는 사각형을 선택하고 다음을 누릅니다. 원형 부품은 원형·타원형을 사용합니다.

고객에게 외곽 회전·좌우반전은 제공하지 않습니다. 좌경첩·우경첩은 각각 등록합니다. 원형·타원형은 단순 위치 지정 방식에서 사용합니다.

6-4. 가로·높이

좌경첩 예시는 다음처럼 설정합니다.

축 치수 방식 입력 고객이 할 수 있는 작업
가로 최소·최대 범위 하한 300 / 이상, 상한 600 / 이하 300~600mm 정수 범위에서 변경
세로 앞 질문의 입력값 사이즈 → H 앞에서 답한 H와 동일, 직접 크기 변경 불가

고정값은 항상 같은 치수이고, 범위는 그 안에서 고객이 조절하며, 앞 질문의 입력값은 고객 답변에 따라 달라지되 고객이 이 도형에서 별도로 조절하지 못합니다.

600 초과 서랍은 가로 하한을 600 / 초과로 지정합니다. 1mm 단위이므로 601부터 허용됩니다. 상한은 해당 제품에서 실제 허용할 값을 정합니다.

원형·타원형의 가로·세로는 각각 지름입니다. 두 값을 같은 고정값 또는 같은 앞 필드에 연결하면 정원이 되고, 서로 다르게 설정하면 타원이 됩니다. 두 축에 독립적인 범위를 주면 고객도 각 지름을 독립 조절합니다.

6-5. 내부 기호·저장

  1. 미리보기 가로/높이로 도형 비율을 확인합니다. 앞 질문 연결값은 아직 고객 답변이 없으므로 예시 숫자로 보여줍니다.
  2. 내부 기호 그리기·수정을 누릅니다.
  3. 오른쪽에서 좌향 삼각형을 선택하고 외곽 안에서 드래그하여 경첩 표시를 그립니다. 선·사각형·원·타원·문자도 사용할 수 있습니다.
  4. 아래 기호 적용을 누릅니다. 내부 편집 창이 닫히고 방금 그린 기호가 이전 도형 등록 창에 보입니다.
  5. 도형 등록 창의 도형저장을 누릅니다. 좌경첩이 여닫이 카드의 도형 목록에 추가됩니다. 내부 편집 화면에서는 도구를 골라 드래그하는 동안 파란 미리보기로 그려질 모양을 확인합니다. 놓으면 도형이 등록되고 선택 도구로 자동 전환합니다. Esc는 그리기를 취소합니다.
  • 선택 / 내부 기호 목록: 선·타원을 쉽게 선택합니다. 마우스 드래그, 우측 중심 X/Y, 방향키로 옮깁니다.
  • 내부 기호의 좌표: 소수 좌표 편집을 허용합니다. 제품에 배치하는 문·서랍의 실제 치수와 위치는 기존대로 1mm 단위입니다.
  • 크기: 조절점을 드래그하거나 우측 가로·높이를 입력합니다. 숫자 입력 후 Enter로 적용할 수 있습니다. 직접 입력에는 자석을 강제로 적용하지 않습니다.
  • 선 끝점: 파란 양끝 점을 드래그해 길이와 방향을 바꿉니다. 우측 시작·끝 X/Y도 입력할 수 있습니다.
  • 선 회전: 둥근 회전점을 드래그하거나 각도·선 길이를 입력합니다. −15°/＋15°/＋90° 버튼도 사용할 수 있습니다. 내부 기호 선을 편집하는 기능이며 고객 문의 회전·반전은 허용하지 않습니다.
  • Shift: 선을 그릴 때 45°, 회전점을 조절할 때 15° 간격으로 맞춥니다.
  • 마그네틱: 바탕과 다른 기호의 변·중앙을 기준으로 안내합니다. 숫자 입력과 방향키 미세 이동은 자석에 다시 끌려가지 않습니다.
  • 복제·삭제·다중 선택·정렬·앞으로/뒤로·실행 취소: 선택한 기호에 적용합니다. 실행 취소·다시 실행 후에도 존재하는 기호의 선택을 유지합니다.

기호 적용 후 바깥 창에서 도형저장까지 진행합니다. 내부 기호는 고객 도형 크기에 맞춰 비례 표시됩니다.

  1. 같은 여닫이 카드에서 ＋ 도형등록을 다시 눌러 우경첩을 등록합니다. 기존 도형을 복사하여 이름과 기호를 바꿀 수도 있습니다.

2단 서랍 예시: 사각형 안에 중앙 가로선을 그려 2칸임을 표현합니다. 이 도형을 한 번 배치하면 해당 서랍 항목의 개수는 1입니다. 1단·2단을 같은 숫자 항목에 연결하면 같은 개수 입력으로 계산합니다. 가격을 따로 구분해야 한다면 숫자 항목도 나누어 등록합니다.

목록의 수정은 해당 도형 등록 창을 다시 열고, 삭제는 현재 편집 중인 설정에서 해당 종류를 제거합니다. 이후 설정 적용과 프로세스 저장까지 해야 반영됩니다. 이미 확정해 보관한 실제품 도면은 당시 정의로 조회합니다.

7. 도면 설정 4단계: 완료 조건

  • 단순 위치 지정: 가구 도면 안·밖에서 위치와 개수를 받습니다. 빈 공간을 남길 수 있습니다.
  • 전체 영역 꽉 채우기: 사각형을 가구 도면 안에 놓아 가로·높이 전체를 채웁니다. 도면 밖에 놓을 수 없습니다.

두 방식 모두 생성된 도형끼리 겹칠 수 없습니다. 맞닿는 것은 가능합니다. 회전·반전은 하지 않습니다. 치수는 관리자 고정값·앞 답변·허용 범위를 그대로 따릅니다.

이동·크기 변경으로 겹침이 생기거나 꽉 채우기 도면을 벗어나면 직전 상태로 돌아갑니다. 새 도형을 놓을 공간이 없으면 생성하지 않으며 개수도 늘어나지 않습니다. 별도의 미배치 단계는 없습니다.

고객은 편집 도중 언제든 도형을 바로 선택해 옮기거나 크기를 바꿀 수 있습니다. 마지막에 확정 하나만 누르며, 그때 채움과 입력 제한을 검사하고 종류별 개수를 전달합니다. 별도의 다시 편집·잠금 해제 단계는 없습니다.

8. 도면 설정 5단계: 고객 화면 시험·확인

  1. 앞 숫자 예시를 W=1500, H=800으로 입력합니다. 다른 앞 질문에 필요한 값도 입력합니다.
  2. 분기에 쓰는 선택형 질문의 답변을 고릅니다.
  3. 고객 배치 화면 시험을 누릅니다.
  4. 현재 분기에서 허용한 타입만 나오는지 확인합니다. 질문 자체가 숨겨지는 조건이면 앞 답변을 바꿔 시험하라는 안내가 나옵니다.
  5. 도형을 배치하고 확정을 누르면 시험 개수를 확인합니다. 이 시험은 실제 고객 주문을 저장하지 않습니다.
  6. 이전 설정 창에서 설정 적용을 누릅니다.
  7. 질문 편집 창에서 나머지 단계를 확인하고 이 질문 완성을 누릅니다.
  8. 프로세스의 전체 검증·등록 단계로 이동하여 전체 경로 검증 → 검증 후 등록완료를 진행합니다.

9. 등록한 타입 5개를 분기에서 3개/2개로 나누는 방법

  1. 해당 질문에 타입 5개와 각 타입의 도형을 모두 등록합니다.
  2. 프로세스 메인의 연관관계 설정 단계로 이동합니다.
  3. 조건의 출발점인 앞 질문에서 이 답변에서 연관관계 설정을 누릅니다. 여러 질문을 함께 조건으로 쓰면 기존 복합 조건·여러 동작 연결을 사용합니다.
  4. 앞 답변의 조건을 정하고, 대상 질문으로 문의 형태를 고릅니다.
  5. 해당 숫자 항목의 표시를 제한하는 연결에서 첫 조건에 보여줄 3개 항목을 선택합니다.
  6. 다른 조건에는 나머지 2개 항목을 연결하고 전체 경로를 검증합니다.

숫자 입력묶음은 기존처럼 묶음 전체가 표시 단위입니다. 3개/2개를 따로 보여주려면 5개를 모두 한 묶음으로 만들지 말고 독립 항목 또는 실제로 표시할 3개 묶음·2개 묶음으로 구성합니다.

고객에게는 현재 허용된 항목 아래의 도형만 나타납니다. 숨겨진 타입은 숫자 답변과 가격계산의 활성 입력에서 제외됩니다. 답변 변경 전에 만든 숨김 타입의 도형이 남아 있으면 다시 편집·확정해야 합니다.

도면 질문의 개수도 기존 숫자 조건에 사용할 수 있습니다. 예를 들어 여닫이 개수 3 이상이면 뒤 질문을 표시하는 연결을 기존 방식으로 만들 수 있습니다.

10. 가격계산에는 어떻게 연결하나요?

대상 제품의 가격계산 화면으로 들어갑니다. 프로세스를 바꾼 뒤라면 최신 프로세스 불러오기로 현재 연결을 확인합니다.

  1. 가격을 구성하는 항에서 옵션별 일괄 설정 또는 ＋ 항 개별 생성을 누릅니다.
  2. 문의 형태의 숫자 항목을 기존처럼 선택합니다.
  3. 가격 정책에 맞게 계산 방식을 등록합니다.
정책 연결 예시 결과
600 이하 서랍 한 개당 40,000원 해당 개수 × 40,000 2개면 80,000원
600 초과 서랍 한 개당 60,000원 해당 개수 × 60,000 1개면 60,000원
개수에 따라 총금액이 달라짐 해당 개수를 축으로 1차원 엑셀 가격표 등록한 표의 금액
한 개 이상일 때 추가금 한 번 개수 > 0 조건 + 고정 금액 개수에 관계없이 한 번 가산
여닫이는 무료 기존 가격 연결 정책에 맞춰 0원으로 설정 개수·도면은 받되 추가금은 0원

고정 금액은 도형이 0개라고 자동으로 0원이 되지 않습니다. 개수가 있어야 받는 금액이면 적용 조건을 함께 설정합니다.

  1. 현재 입력으로 가격 테스트에서 고객처럼 앞 질문을 답합니다.
  2. 도면 질문의 답변하기를 눌러 실제 도형을 배치하고 확정을 누릅니다.
  3. 현재 입력으로 가격계산을 눌러 집계 개수와 항별 계산 근거를 확인합니다.
  4. 다른 분기의 앞 답변으로 바꿔 반복하고, 누락·중복·계산 범위 검사를 실행합니다.
  5. 테스트 확인 후 가격계산식 저장을 누릅니다.

도면에서 나오는 개수도 기존 가격 항의 조건·분기·배율·엑셀에 연결할 수 있습니다. 입력 방식만 바뀌며 기존 가격 기능을 대체하지 않습니다.

11. 고객이 실제로 사용하는 순서

  1. 발주하기에서 비규격 제품을 찾고 앞 질문을 차례로 답합니다.
  2. 사이즈에 W=1500, H=800 등을 입력합니다.
  3. 문의 형태에서 답변하기를 누릅니다.
  4. 오른쪽의 ＋ 좌경첩, ＋ 우경첩 등 원하는 종류를 누릅니다. 겹치지 않는 위치에 생성됩니다.
  5. 선택 도구로 도형을 누르거나 오른쪽 배치 도형 목록에서 선택합니다. 내부 경첩 기호를 눌러도 문 전체가 선택됩니다.
  6. 도형을 이동하거나 조절점을 드래그합니다. 오른쪽 중심 X/Y·가로·높이에 숫자를 입력해도 됩니다. 고정·앞 답변 축은 잠기며 범위 축만 크기를 바꿀 수 있습니다.
  7. 마지막 확정을 누릅니다. 꽉 채우기라면 전체가 채워져야 하며, 기존 숫자 최소·최대·합계 제한도 확인합니다.
  8. 이전 질문 화면에 종류별 개수와 도면이 반영됩니다. 다음 질문으로 진행합니다.
  9. 확정한 답변을 바꾸려면 질문 화면의 배치 수정을 엽니다. 별도 편집 해제 없이 바로 수정하고 확정하면 됩니다.

배치 편의 기능

  • 경계·도형에 붙이기: 가까운 변·중앙에 마그네틱을 적용합니다. 다중 선택을 옮길 때는 상대 위치를 유지합니다.
  • Shift+클릭 / Ctrl+A: 여러 개 선택 / 전체 선택.
  • 복제 / Ctrl+D, 삭제 / Delete: 선택한 도형에 적용합니다. 공간이 없는 복제는 적용하지 않습니다.
  • 방향키 / Shift+방향키: 1mm / 10mm 이동.
  • 실행 취소 / 다시 실행: 삭제·배치·크기 변경을 되돌립니다.
  • 여러 개 정렬: 여러 도형을 선택하면 왼쪽·오른쪽·위·아래·중앙 정렬 버튼이 나옵니다. 겹침이 생기는 정렬은 적용하지 않습니다.
  • 마우스 휠: 가리키는 위치를 기준으로 조금씩 확대·축소. Shift+휠은 가로 이동, Alt+휠은 일반 스크롤입니다.
  • 전체 보기: 외부 배치 부품과 치수 표시까지 들어오도록 맞춥니다.
  • 모눈 / 눈금 / 개별 치수: 필요한 표시를 켜거나 끕니다.

12. 중앙 좌표·외부 치수·눈금을 읽는 방법

기본 가구 도면의 중앙이 (0,0)입니다. 오른쪽은 +X, 왼쪽은 −X, 위쪽은 +Y, 아래쪽은 −Y입니다. 좌표 기준점이나 전체 좌표축을 가구 안에 표시하지 않습니다.

좌표·치수 숫자와 간격 숫자는 가구와 배치 부품을 모두 포함한 바깥 영역에 표시합니다. 가구 내부에 숫자를 덮어쓰지 않습니다. 위치 지정 부품이 가구 밖에 있어도 그 부품을 가리지 않도록 표시 영역을 확장합니다.

표시 의미
위쪽 눈금 중앙 기준 X 좌표
왼쪽 눈금 중앙 기준 Y 좌표
100mm 굵은 점·숫자 기본 큰 눈금
10mm 작은 점 기본 작은 눈금
전체 가로·높이 치수선 가구 도면의 전체 치수, 양끝 화살표로 범위 표시
아래쪽 개별 치수 문·서랍의 각 폭. 같은 구간은 중복 표시를 줄임
오른쪽 개별 치수 각 높이
선택 도형의 외부 표시 중심 좌표와 이웃 도형·외곽까지의 간격

확대 배율이 너무 낮으면 눈금이 겹치지 않도록 표시 간격을 자동으로 넓힙니다. 확대하면 100/10mm 눈금을 더 자세히 볼 수 있습니다.

예를 들어 1500×800mm 도면을 500×800mm 문 세 개로 채우면 각 중심 X는 −500, 0, +500mm이고 중심 Y는 모두 0입니다.

입력 치수와 실제 배치 간격은 1mm 단위입니다. 홀수 치수에서는 정확한 중앙 좌표가 0.5mm로 표시될 수 있으며, 실제 위치를 소수로 저장한다는 뜻은 아닙니다. 원형·타원의 간격은 외접 경계의 수평·수직 투영 기준입니다.

13. 앞 답변이나 도형 설정을 바꿨을 때

앞 W/H를 바꾸면 기존 배치를 임의로 비례 확대하지 않습니다. 같은 진행 중에는 이전 위치를 미확정 초안으로 보관하고, 배치 수정에서 새 치수와 허용 타입을 확인하여 확정을 다시 눌러야 합니다.

앞 분기로 숨겨진 타입, 새 도형 범위를 벗어난 치수, 새 바탕 밖으로 나간 위치는 그대로 확정할 수 없습니다. 기존 타입을 삭제하거나 수정한 뒤의 저장 상품도 다시 확인합니다.

종류별 개수와 배치가 모두 같은 구성을 수량 2개로 주문하면 동일 도면의 제품 2개입니다. 서로 다른 배치를 주문하려면 각각 구성해 별도 품목으로 넣습니다.

14. 관리자·생산·관리 담당자가 확정 도면을 보는 방법

관리자: 비규격 제품 관리 → 해당 제품의 실 제품·재고 → 해당 실제품의 확정 배치 도면을 누릅니다. 이 버튼은 해당 실제품 답변에 배치 도면이 저장되어 있을 때 표시됩니다.

조회 권한이 있는 직원은 /team/product-diagram/actuals/실제품ID에서도 열 수 있습니다. 도형을 선택하면 중심점·치수·위치를 확인하고 출력으로 인쇄할 수 있습니다. 도면이 여러 개면 위의 도면 1 / 도면 2 버튼으로 전환합니다.

조회 화면에서 원본을 수정하지 않습니다. 이후 관리자 수정 기능에 사용할 수 있도록 좌표·치수·도형 종류·내부 기호를 포함한 원본 데이터는 보관합니다.

현재 고객 발주하기는 실제 접수·결제 전의 미리보기 단계입니다. 이 기능을 적용했다고 기존 생산 Order 상세에 도면이 자동 연결되는 것은 아닙니다. 현재 저장 상품·구성 복원·최종 미리보기와 기존 실제품 등록·조회에서 사용할 수 있습니다.

15. 필요한 버튼이 없거나 진행되지 않을 때

상황 확인·조치
웹다이어그램 단계가 없음 해당 그룹이 고객 질문에 포함된 비규격 숫자입력이며 가격계산 영향이 켜져 있는지 확인
도면 응답 설정 바로가기 없음 먼저 답변 등록·수정에서 개수 입력 항목을 등록. 대상이 아닌 질문에는 버튼 미표시
앞 질문 선택 목록이 비어 있음 숫자 필드가 등록된 질문을 현재 질문 앞에 배치
가로·높이를 못 읽음 해당 분기에서 원본 숫자 필드를 실제로 받는지 확인. 양의 정수 mm로 입력
600 초과 도형을 600으로 못 만듦 정상적인 제한. 601 이상 또는 원하는 범위 정의로 수정
고객에게 일부 타입이 안 나옴 현재 앞 분기의 허용 항목과 도형 자체 표시 조건을 함께 확인
도형은 그렸는데 설정 목록에 없음 내부 편집의 기호 적용 후 이전 창에서 도형저장까지 진행
목록에는 있는데 고객에게 반영되지 않음 설정 적용 → 이 질문 완성 → 검증 후 등록완료, 필요한 가격식 재검증까지 확인
전체 채우기에서 확정 불가 빈 영역·겹침·영역 이탈과 종류별 최소·최대 개수 확인. 전체 W×H를 채워야 함
가격식이 이전 구성이라고 표시됨 프로세스 저장 후 가격계산에서 최신 프로세스 불러오기 → 검사·테스트·가격계산식 저장
실제품이 있어 수정이 잠김 기존 잠금 정책 적용. 원본을 보존하려면 제품을 복사해 새 구성에서 수정
확정 배치 도면 링크가 없음 해당 실제품이 도면 응답으로 등록되었는지 확인. 기존 일반 숫자 답변만 있는 실제품에는 링크 없음

운영 한도는 항목 20개, 질문별 도형 종류 100개, 종류별 내부 기호 100개, 질문별 배치 500개입니다. 실제 배치는 기존 질문 제한과 치수·겹침·영역·채움 검증을 모두 통과해야 확정됩니다.

이번 버전 적용 후 확인

단순 위치 지정은 가구 밖 배치를 허용하므로 가구 면적을 개수 상한으로 사용하지 않습니다. 기존 항목 최대 개수와 전체 500개 제한은 유지합니다. 기존 위치 지정 제품의 가격식은 가능한 개수 범위를 다시 확인하도록 재검증 필요가 표시됩니다. 최신 프로세스 불러오기 → 검사·테스트 → 가격계산식 저장을 진행하세요. 일반 숫자입력과 꽉 채우기의 가격식 식별값은 유지됩니다.
